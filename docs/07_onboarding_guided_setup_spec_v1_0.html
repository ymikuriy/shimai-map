07_初回操作ガイド仕様書_v1.0

初回利用時に、実際のアプリ画面上でポップアップ/ハイライトを表示し、ユーザー自身の操作で「部屋1件・収納1件・アイテム1件の登録」と「検索結果確認」まで進めるチュートリアル仕様。

実画面ガイド操作ロックゲーム初回デモ型

1. 目的

この仕様は、独立した説明画面ではなく、実アプリ画面にガイドを重ねる初回チュートリアルである。
ユーザーは通常のアプリ画面を見ながら、指定された操作だけを順番に実行し、検索できる状態まで体験する。
完了条件
部屋1件、収納1件、アイテム1件が登録され、検索結果から位置表示まで確認済み。
表示方式
実画面 + 暗転オーバーレイ + 対象ハイライト + 吹き出し説明。
操作制御
ガイド中は、現在ステップの対象操作以外を実行できない。

2. 基本方針

項目方針
開始画面ログイン後、通常の検索/アイテム一覧画面を表示する。アイテム・部屋が0件の状態から始める。
ガイド形式「はじめに」等の専用説明画面は作らない。実際に使う画面上にポップアップで補足する。
操作ロック現在のステップで必要なボタン、入力欄、リスト行だけを有効化する。それ以外はタップ不可。
完了方法登録したアイテムを検索し、位置表示画面を確認した時点で自動的に完了扱いにする。明示的な「ガイドを完了する」ボタンは置かない。

3. 対象範囲

対象扱い備考
部屋登録対象例として「玄関」を登録する想定。ユーザー入力は可能。
収納追加対象部屋レイアウト編集で収納を1つ追加し、保存する。
アイテム登録対象例として「レインコート」を登録し、格納先に作成した収納を指定する。
検索確認対象登録したアイテムを検索し、位置表示画面を開く。
カテゴリ/人物ラベル対象外初回ガイドでは必須操作にしない。通常仕様に従う。
詳細なレイアウト調整対象外収納追加の最小操作だけを行う。サイズ変更・詳細移動は通常仕様に従う。

6. 操作制限ルール

項目仕様
操作可能領域ハイライトされた入力欄、ボタン、リスト行のみ操作可能。
操作不可領域ハイライト外のボタン、リスト、設定項目、戻る操作はタップしても反応しない。
画面表示実アプリ画面を表示し、非対象領域は暗転または薄く表示する。
入力補助例として「玄関」「棚1」「レインコート」をプレースホルダー/初期候補として表示してよい。ただしユーザーは変更可能。
バリデーション各画面の通常仕様に従う。保存条件を満たすまで保存ボタンは無効。
完了後位置表示画面を初回確認した時点で onboarding_status を completed に更新し、通常操作ロックを解除する。

guided_item_idid/null初回ガイドで作成したアイテムID。

8. 仕様ID

ID仕様
OG-001初期データがないアカウントは、ログイン後に検索/アイテム一覧画面へ遷移し、実画面上で初回操作ガイドを開始する。
OG-002初回操作ガイドでは、専用の「はじめに」画面や「ガイドを完了する」ボタンを表示しない。
OG-003ガイド中は、現在ステップで指定された操作対象以外を操作不可にする。
OG-004ガイドの完了条件は、部屋1件、収納1件、アイテム1件の登録、および登録アイテムの検索/位置表示確認とする。
OG-005途中離脱時は、作成済みデータと current_onboarding_step をもとに、未完了ステップから再開する。
OG-006初回ガイドで作成した部屋・収納・アイテムは通常データとして保存し、ガイド完了後もそのまま利用する。
OG-007初回操作ガイドはゲームの初回デモと同様に、ユーザーが実操作しながら学習する体験として設計する。
