部屋・収納・エリア編集仕様書
v1.0

部屋の登録、部屋レイアウト編集、収納レイアウト編集を定義する。アイテム登録時の格納先選択、および検索後の位置表示で利用する部屋・収納・エリア構造を作るための仕様書。

1. 概要

目的：ユーザーが部屋、収納、収納内エリアを視覚的に作成・編集し、アイテムの所在を「部屋 ＞ 収納 ＞ エリア」として表現できる状態にする。

部屋

部屋名、メモ、部屋レイアウト、配置済み収納リストを管理する。

収納

部屋レイアウト上に青線の矩形として配置する。収納同士の重なりは禁止。

エリア

収納レイアウト上に緑線の矩形として配置する。アイテムの詳細位置として任意利用する。

2. 対象範囲

本仕様書で扱う

・部屋登録/編集

・部屋レイアウト表示/編集

・収納の追加、選択、サイズ変更、移動

・目印の追加、選択、サイズ変更、移動

・収納レイアウト編集

・エリアの追加、選択、サイズ変更、移動

・収納/目印/エリアの選択状態表示

本仕様書では扱わない

・アイテム登録/編集画面そのもの

・検索/結果表示画面

・保存後/キャンセル時の戻り先確定

・削除操作の詳細

・複数端末同時編集の競合解決

部屋レイアウト編集ルール

対象仕様
レイアウト表示枠スマホ画面内に収まる幅で表示する。外側の表示枠は角丸可。ただし、部屋枠・収納・目印の矩形自体は角丸にしない。
部屋の形状タブ正方形、縦長、横長から選択。選択すると表示エリアの部屋枠がリアルタイムに切り替わる。
収納＋タブ押し入れ、クローゼット、タンス、棚、靴箱などから収納を追加する。青線・青文字の矩形で表示し、角は丸めない。
目印＋タブ入口、ドア、窓、キッチン、ベッドなどから目印を追加する。灰色ベースの矩形で表示し、角は丸めない。部屋枠線の内外に配置可能。
詳細移動タブ選択中要素の幅、高さ、上下左右位置をコンパクトに微調整できる。名称変更は選択中カード内の入力欄で行う。
移動選択中要素の中央をドラッグアンドドロップすると移動する。詳細移動タブでは上下左右ボタンでも微調整できる。
サイズ変更選択中要素の枠線をドラッグアンドドロップするとサイズ変更する。詳細移動タブでは幅＋/幅−/高さ＋/高さ−でも変更できる。
選択中表示タブに関係なく、選択中要素はレイアウト下にコンパクト表示する。収納は「収納名」、目印は「目印名」の横に名称入力欄を置く。未選択時は「未選択」と表示する。収納/目印でカードの高さは変えない。収納の場合はアイテム件数、収納レイアウト状態を説明テキストとして表示し、収納レイアウト編集導線のみボタン風に表示する。
追加時の命名同一種別ごとに「棚1」「棚2」「ドア1」のように連番付与。
追加位置初期案：左上から空き領域を探索して自動配置。配置不可の場合は追加せず警告。詳細アルゴリズムはTBD。

収納レイアウト編集ルール

対象仕様
選択中パス画面上部に「選択中：部屋 ＞ 収納 ＞ エリア」の形式で現在の選択パスを表示する。エリア未選択時も親階層は残し、「選択中：部屋 ＞ 収納 ＞ 未選択」と表示する。
収納枠部屋レイアウトで作成された収納の形をベースに、画面上では大きめに表示する。収納枠自体はこの画面では固定。
エリア緑線・緑文字の矩形。角は丸めない。収納枠の内側にのみ配置可能。エリア同士の重なりは禁止。
タブ「エリア＋」「詳細移動」の2タブで操作パネルを切り替える。目印は収納レイアウトには存在しない。
選択中表示選択中エリアはレイアウト下にコンパクト表示し、「エリア名」の横に名称入力欄を置く。未選択時は「未選択」と表示する。アイテム件数は説明テキストとして表示し、アイテム追加導線のみボタン風に表示する。エリアリストは表示しない。
移動選択中エリアの中央ドラッグで移動する。詳細移動タブでは上下左右ボタンでも微調整できる。
サイズ変更選択中エリアの枠線ドラッグでサイズ変更する。詳細移動タブでは幅＋/幅−/高さ＋/高さ−でも変更可能。
追加時の命名エリア1、エリア2のように連番付与。
エリア追加小・中・横長・縦長などのデフォルト形状から選択して追加。
追加位置初期案：収納内の空き領域を探索して自動配置。配置不可の場合は追加せず警告。詳細アルゴリズムはTBD。

8. 共通編集ルール

選択とハイライト

レイアウト上で要素を選択すると、該当要素をハイライトし、選択中要素の情報に反映する。

選択中カードには、名称入力欄、種別、件数、関連画面への導線をコンパクトに表示する。件数や状態は説明テキスト、遷移導線はボタン風に表示する。

移動とサイズ変更

要素の中央ドラッグで移動し、枠線ドラッグでサイズ変更する。

詳細移動タブでは、上下左右ボタンと幅/高さボタンをコンパクトにまとめて微調整できる。名称変更は選択中カード内の入力欄で行う。

重なり制御

部屋レイアウト：収納同士の重なりは禁止。

収納レイアウト：エリア同士の重なりは禁止。

配置可能範囲

収納は部屋枠の内側のみ。

目印は部屋枠の内外に配置可能。

エリアは収納枠の内側のみ。

図の収まり

すべてのレイアウト図は、スマホ画面内に収まるサイズで表示する。

外側の表示枠は角丸可。部屋枠・収納・目印・エリアの矩形は角丸にしない。

選択中パス

R02/R03の上部に、現在選択している要素のパスを表示する。

例：選択中：玄関 ＞ 玄関収納1 ＞ エリア2

未選択時も親階層は残す。例：選択中：玄関 ＞ 未選択 ／ 選択中：玄関 ＞ 玄関収納1 ＞ 未選択

9. データ項目

データ主な項目補足
部屋room_id、部屋名、メモ、部屋形状部屋名は必須。メモは任意。
収納storage_id、room_id、名称、種別、x/y、幅/高さ、アイテム件数、収納レイアウト有無部屋に所属し、部屋レイアウト上に配置される。
目印landmark_id、room_id、名称、種別、x/y、幅/高さドア、窓など。位置を把握するための背景要素。
エリアarea_id、storage_id、名称、x/y、幅/高さ、アイテム件数収納内の詳細位置。アイテム登録時は任意。
