08_共通データルール仕様書_v1.0

削除ルール、1ユーザー=1家、レイアウト初期配置、AI機能の扱いなど、複数仕様書にまたがる共通ルール。

共通ルール削除AI検討

1. 目的

各仕様書にまたがるデータ運用ルールを固定する。
AI開発エージェントが削除、初期配置、アカウント単位、AI範囲を勝手に解釈しないようにする。

2. アカウント/家の単位

MVP
1ユーザー = 1家。ログイン後、そのユーザー専用のHomeSpaceを1つ自動作成する。
Phase2
家族共有、複数の家、招待/権限管理を検討する。
注意：MVPでは家の切替UI、家族招待UI、共有権限UIは作らない。

3. 削除ルール

対象削除条件関連データの扱い表示/確認
部屋収納またはアイテムがある場合は削除不可空の場合のみ削除可能削除不可理由を表示
収納アイテムがある場合は削除不可空の場合のみ削除可能削除不可理由を表示
エリア削除可能該当エリア内アイテムは「エリア未指定」に戻す影響件数を表示して確認
目印削除可能アイテムには影響しない確認ダイアログ
人物ラベル削除可能該当アイテムからラベルを外す影響件数を表示して確認
カテゴリ削除可能該当アイテムからカテゴリを外す影響件数を表示して確認
アイテム削除可能所在情報、タグ、AI検索補助語も削除確認ダイアログ

4. レイアウト要素の初期配置ルール

対象配置範囲重なり初期配置
収納部屋枠線の内側のみ収納同士の重なり禁止左上から空きスペースを探索して配置
目印部屋枠線の内外可能原則、視認性を損なう重なりは避ける種類ごとの推奨位置に配置。例：窓は枠線外側、ドア/入口は枠線付近
エリア収納枠線の内側のみエリア同士の重なり禁止左上から空きスペースを探索して配置
空きスペースがない場合：中央に仮配置し、「重なっています。位置またはサイズを調整してください」と警告する。保存時には重なり禁止ルールを満たす必要がある。

5. レイアウト共通ルール

  • スマホ画面からレイアウト図が飛び出す表示はNG。
  • 部屋枠、収納、目印、エリアの矩形は角丸なし。外側の表示用枠は角丸可。
  • 中央ドラッグは移動、枠ドラッグはサイズ変更。
  • 詳細移動タブでは、幅/高さ/上下左右の微調整を行う。
  • 名前変更は選択中カード内の名称入力欄で行う。

6. AI機能の扱い

MVP候補
  • カテゴリ候補生成
  • 検索補助語生成
AI開発エージェントに検討させること
  • APIコスト
  • レスポンス速度
  • 個人情報送信範囲
  • ルールベース代替案
  • 検索時フォールバックのPhase2実現性
MVPで避けること：AIによる所在推定、検索時の毎回AI API呼び出し、画像認識による自動登録は原則対象外。

7. 仕様ID

ID仕様
CR-001MVPでは1ユーザー=1家とする。
CR-002部屋は収納またはアイテムがある場合、削除不可とする。
CR-003収納はアイテムがある場合、削除不可とする。
CR-004エリア削除時、そのエリア内アイテムはエリア未指定に戻す。
CR-005人物ラベル/カテゴリ削除時、該当アイテムから対象タグを外す。
CR-006レイアウト要素追加時は、左上から空きスペースを探索して初期配置する。
CR-007空きスペースがない場合は中央仮配置とし、重なり警告を表示する。
CR-008AI機能のMVP範囲は、AI開発エージェントによる実現可否/コスト評価後に最終確定する。
