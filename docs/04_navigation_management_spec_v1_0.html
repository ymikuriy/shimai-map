全体画面遷移・管理設定仕様書

検索をアプリの主画面とし、下部タブは設けず、右上のアイテム追加・設定アイコンから登録/管理系へ遷移する方針を定義する。

メイン：検索/アイテム一覧 右上：＋ アイテム追加 右上：設定アイコン 下部タブなし

1. 概要

本仕様書では、アプリ全体の画面入口、管理画面、主要な戻り先を整理する。

結論：下部タブは作らない。アプリ起動時は「検索/アイテム一覧」を表示し、管理系は右上の設定アイコンから入る。
主目的
モノを検索して所在を確認する。
日常導線
検索 → アイテム選択 → 位置表示。
管理導線
設定アイコン → 管理画面 → 部屋/人物/カテゴリ/アカウント管理。

2. 基本方針

項目方針理由
下部タブ作らない検索が主目的であり、管理機能を常時見せる必要が低いため。
検索/アイテム一覧1画面に統合検索前は全アイテム一覧、検索後は絞り込み一覧にするのが自然。
アイテム追加メイン画面右上の「＋」から遷移検索中に登録したいケースが多く、入口を明確にできる。
管理/設定メイン画面右上の設定アイコンから遷移部屋・収納・ラベル・カテゴリ・アカウントは初期設定/メンテナンス寄りのため。
収納管理独立メニューにはしない収納は部屋に所属するため、部屋管理から編集する。

7. 共通ルール

右上アイコン

＋ はアイテム追加専用。⚙ は管理/設定専用。検索画面の主役はあくまでアイテム検索/一覧とする。

戻る/キャンセル

未保存変更がある場合のみ確認ダイアログを表示する。未変更の場合は即時戻る。

管理メニュー

収納管理は独立メニューにしない。収納は部屋に所属するため、部屋管理内で扱う。

スマホ設計書表示

ワイヤーフレーム内の図・リスト・カードはスマホ枠からはみ出さない。横幅が狭い場合は折り返す。

既存仕様書への影響

01 検索仕様S01/S02を「検索/アイテム一覧画面」に統合する差分修正が必要。
02 アイテム登録保存後遷移のTBDを、本仕様の戻り先ルールに合わせて更新可能。
03 部屋/収納管理画面から部屋管理へ入り、R01/R02/R03へ遷移する導線として整理。

8. 仕様ID一覧

ID仕様
NV-001下部タブは設けず、アプリ起動時はM00 検索/アイテム一覧を表示する。
NV-002M00右上にアイテム追加用の「＋」と、管理/設定用の設定アイコンを配置する。
NV-003検索前は全アイテム一覧、検索後は検索条件に合うアイテム一覧を同じ領域に表示する。
NV-004管理/設定画面には、部屋管理、人物ラベル管理、カテゴリ管理、アカウント設定を表示する。
NV-005収納管理は独立メニュー化せず、部屋管理内の部屋レイアウト/収納レイアウト導線で扱う。
NV-006検索文脈でのアイテム追加保存後は、S03 位置表示へ遷移し登録結果を確認する。
NV-007管理文脈での追加/編集保存後は、原則として呼び出し元の管理画面へ戻る。
NV-008未保存変更がある状態で戻る場合のみ、確認ダイアログを表示する。
NV-009設計書上のスマホワイヤーフレームは、図・リスト・カードがスマホ枠からはみ出さないようにする。
