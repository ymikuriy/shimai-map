アイテム登録・編集仕様書
v1.0

家の中のモノを検索で見つけられる状態にするため、アイテム名・格納先・人物ラベル・カテゴリを登録/編集する画面仕様を定義する。 保存後の戻り先は、アイテム追加/編集の入口が全体整理できるまでTBDとする。

1. 概要

目的：ユーザーがアイテムを「検索でヒットし、位置表示できる状態」で登録/編集できるようにする。

登録の最小条件

アイテム名と格納先の収納まで設定されていること。

アイテム名 + 部屋 + 収納

任意情報

エリア、人物ラベル、カテゴリは任意。未設定でも保存できる。

検索連携

保存時にAI検索補助語を内部生成し、検索対象に含める。

2. 対象範囲

本仕様書で扱う

・アイテム新規登録画面

・アイテム編集画面

・保存条件、バリデーション

本仕様書では扱わない

・部屋/収納/レイアウトの作成・編集

・人物ラベル設定画面の詳細

・カテゴリ設定画面の詳細

・アイテム追加/編集の全入口整理

・保存後/キャンセル時の戻り先確定

I03 ルール

対象動作
人物ラベル検索UIは持たない。既存ラベル一覧からタップで複数選択/解除する。
人物ラベル追加右上の「追加」で新規人物ラベルを作成し、選択済みとして反映する。

カテゴリ追加AI候補にない場合のみ文字列入力する。既存カテゴリ名と完全一致した場合は既存カテゴリを付与し、一致しない場合のみ新規カテゴリを作成する。

9. バリデーション

条件保存可否表示/動作
アイテム名が空不可保存ボタン無効。必要に応じて「アイテム名を入力してください」。
格納先未選択不可保存ボタン無効。必要に応じて「格納先を選択してください」。
収納まで選択済み、エリア未指定可正常扱い。所在パスは「部屋 ＞ 収納」。
人物ラベル未設定可正常扱い。
カテゴリ未設定可正常扱い。AI検索補助語により検索補助する。
カテゴリ候補取得失敗可「候補を取得できませんでした。手動で追加できます。」と表示。

10. 仕様ID一覧

IR-001
アイテム登録/編集では、アイテム名を必須とする。
IR-002
格納先は収納まで必須とする。エリアは任意とする。
IR-003
格納先選択は、部屋 → 収納 → エリアの1画面ステップ式とする。
IR-004
部屋を変更した場合、選択済みの収納とエリアをリセットする。
IR-005
収納を変更した場合、選択済みのエリアをリセットする。
IR-006
人物ラベルは任意・複数選択可とする。選択画面に検索UIは置かず、既存リストから選択する。
IR-007
カテゴリは任意・複数選択可とする。カテゴリの検索/選択画面は持たず、AI候補または文字列追加で設定する。
IR-008
カテゴリ欄付近にAI候補ボタンを配置し、ユーザー操作時のみ候補を表示する。
IR-009
AIカテゴリ候補は自動保存せず、ユーザーが選択したものだけ保存する。
IR-010
AI検索補助語は保存時に内部生成し、画面には表示しない。
IR-011
検索結果0件から新規登録する場合、検索キーワードをアイテム名に初期セットする。
IR-012
保存後遷移先・キャンセル時戻り先は、全体画面遷移図作成後に確定する。
IR-013
I01の保存アクションは右上に集約し、下部の保存ボタンは表示しない。
IR-014
I02では、選択中の部屋・収納・エリアを選択中パスにリアルタイム表示する。
IR-015
I02では収納選択後、右上保存によりエリア未指定のまま登録/反映できる。
IR-016
新規人物ラベル/新規カテゴリの追加は右上の「追加」で確定し、下部の追加ボタンは表示しない。
IR-017
I02の選択中パスは1行表示とし、長い場合は省略表示する。
IR-018
I02のエリア選択では、収納エリア図を部屋レイアウトと同等サイズで表示し、未指定アイコンを図の右下に配置する。
IR-019
カテゴリ追加時、入力文字列が既存カテゴリ名と完全一致する場合は既存カテゴリを付与し、一致しない場合のみ新規カテゴリを作成する。
IR-020
I01は新規登録と編集で共通利用し、画面レイアウトは同一、タイトル・初期表示・保存処理のみモードに応じて切り替える。
